# SWYNEX Internship – Final Bioinformatics Report

## Project Title
Bioinformatics Analysis of Breast Cancer Gene Expression Data Using Microsoft Excel

## Project Overview
This project focuses on the basic analysis of a breast cancer gene expression dataset obtained from the NCBI Gene Expression Omnibus (GEO) database.

The selected dataset, GSE42568, contains gene expression information from 121 samples, including breast cancer and normal breast tissue samples.

## Work Performed
- Selected and described the biological dataset.
- Imported and cleaned the dataset using Microsoft Excel 2013.
- Checked for missing values and duplicate probe IDs.
- Calculated mean, median, maximum and minimum values.
- Created a scatter plot and a clustered column chart.
- Calculated the correlation coefficient between two selected samples.
- Interpreted the results and discussed the limitations.

## Key Result
The Pearson correlation coefficient between Sample 1 and Sample 2 was **0.8781**, indicating a strong positive linear relationship.

## Tools Used
- NCBI GEO
- Microsoft Excel 2013
